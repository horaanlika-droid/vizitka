# vizitka

Бот-витрина (Telegram) + веб (Mini App / лендинг) + админ-бот.
Запуск: aiogram polling + aiohttp веб в одном процессе.

## Деплой на Ботхост — правило «секреты только в панель»

В панель Ботхоста вводим **только секреты**:

```ini
BOT_TOKEN=123456:твой-токен
ADMIN_BOT_TOKEN=123456:токен-админ-бота
ADMIN_PANEL_TOKEN=свой-пароль-для-админки
# если оплата через GRAM API:
GRAM_API_KEY=...
GRAM_WEBHOOK_SECRET=...
```

Всё остальное (адрес сайта `SITE_PUBLIC_URL`, контакты, ссылка оплаты,
каналы, админы, порт, флаги запуска) **зашито в код** — блок `SITE_*`
в начале `config.py`. Перед первым деплоем замени там `SITE_PUBLIC_URL`
на реальный адрес проекта (Ботхост даёт его при создании, вида
`https://bot-123.bothost.ru`).

ENV-переменная, если задана, имеет приоритет над значением из кода.
Полный список переменных и пояснения — в `.env.example`.

## Локальный запуск

```bash
cp .env.example .env   # впиши токены в .env
```

Точка входа `main.py` (запускающая config → db → web → боты одним
процессом) пока не добавлена в репозиторий — добавим её при сборке
лендинга под Ботхост. Части запускаются по отдельности:
`run_client_bot()` / `run_admin_bot()` из `bots/*`, веб — из `web/`.

Для локального превью веба без Telegram можно временно поставить
`ALLOW_DEV_AUTH=1` (на проде обязательно `0`).
