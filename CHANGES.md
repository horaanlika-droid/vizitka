### 2. 🔥 Горячее предложение (Hot Offer)

**Новая функциональность:** Горячее предложение, которое отображается сверху на веб-витрине с анимацией пульсации.

#### Возможности:
- ✅ Создание горячего предложения с текстом, ценой и фото
- ✅ Редактирование текста, цены и фото
- ✅ Активация/деактивация предложения
- ✅ Удаление предложения
- ✅ Автоматическое отображение на главной странице витрины

#### Управление через админ-бот:

В главном меню админ-бота появилась кнопка **"🔥 Горячее предложение"**.

**Создание предложения:**
1. Нажми "🔥 Горячее предложение" в главном меню
2. Нажми "➕ Создать предложение"
3. Введи текст (например: "Скидка 20% на все сессии!")
4. Введи цену (например: "500 ₽" или "50 GRAM") или "-" если без цены
5. Пришли фото или "-" если без фото

**Редактирование:**
- ✏️ Изменить текст
- 💰 Изменить цену
- 🖼 Изменить фото

**Управление статусом:**
- 🟢 Включить - предложение отображается на витрине
- ⚫️ Выключить - предложение скрыто, но сохранено
- 🗑 Удалить - полностью удалить предложение

## 🔧 Технические детали

### Хранение данных

Горячее предложение хранится в таблице `settings`:
- `hot_offer_text` - текст предложения
- `hot_offer_active` - статус (1 = активно, 0 = неактивно)
- `hot_offer_photo` - file_id фото (Telegram)
- `hot_offer_price` - цена (строка)
- `hot_offer_emoji` - эмодзи (по умолчанию 🔥)

### API Endpoint

```
GET /api/hot_offer

Response (если активно):
{
  "ok": true,
  "offer": {
    "text": "Скидка 20% на все сессии!",
    "is_active": true,
    "photo_file_id": "AgACAgIAAx...",
    "price": "500 ₽",
    "emoji": "🔥"
  }
}

Response (если неактивно или не создано):
{
  "ok": true,
  "offer": null
}
```
